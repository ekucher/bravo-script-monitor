# BRAVO Script Monitor Roadmap

## v0.1.0-alpha — Foundation

- структура репозиторію;
- базова документація;
- ADR/RFC templates;
- Docker Compose для локальної розробки;
- каркас FastAPI;
- каркас PowerShell Agent;
- базовий CI.

## v0.2.0-alpha — Backend Foundation

- PostgreSQL і Alembic;
- конфігурація та structured logging;
- health/readiness/version endpoints;
- базова модель користувачів, організацій та агентів.

## v0.3.0-alpha — Agent Protocol

- реєстрація агента;
- heartbeat;
- локальна черга;
- передача подій і результатів.

## v0.4.0-alpha — Web Console

- React + TypeScript;
- автентифікація;
- Dashboard;
- агенти, виконання, події.

## v1.0.0

- production-ready BSM Server;
- Windows Agent;
- RBAC;
- аудит;
- виконання завдань;
- історія й базові звіти;
- резервне копіювання та документоване відновлення.
